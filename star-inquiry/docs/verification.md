# 검증 기록

검증일: 2026-10-28. 이 문서는 자동 검증과 실물/브라우저 검증의 범위를 구분한다. 실물 장비가 없으므로 이지메이커 또는 마퀸의 실제 동작을 완료 항목으로 표시하지 않는다.

## 자동 테스트

프로젝트 폴더에서 `npm test`를 실행했다. 최초 15개 테스트 통과 후 CSV 원본 보존·보정 설정 혼합 방지·그래프 누락 구간을 보완하여 **18개 테스트가 모두 통과**했다. 실패 0, 건너뜀 0. `src/domain.test.ts`에 실제 실행 가능한 테스트가 있다.

| 검사 | 확인한 동작 |
| --- | --- |
| 원본과 보정 | 원본 값은 그대로 두고 주변광만 별도 계산한다. 보정 후 0과 음수는 그대로 표시하며 양수로 대체하지 않는다. |
| 분석 유효성 | 누락, 포화 표시, 포화 상한, 분석 제외 사유가 반영된다. |
| 거리 추정 | 실제 속력과 주행 기준 시점이 둘 다 없으면 시간→거리 변환하지 않는다. 출발 전 시점·음수 기준 시점·0 이하 거리/속력을 거부한다. 직접 입력한 유효 거리는 사용할 수 있다. |
| 정규화 | 선택한 유효한 기준점으로 측정값과 역제곱 모형을 계산한다. 거리 0에서 계산하지 않는다. |
| 등급 변화 | 밝기 1/100은 +5, 100배는 −5이다. 0·음수·무한대·NaN은 계산하지 않는다. |
| 선형성 제한 | 단위와 선형성 조건이 충족되지 않으면 실제 측정값의 등급 환산을 허용하지 않는다. |
| 연습 출처 | 연습 데이터 CSV 내보내기→불러오기에서도 연습 표시와 보정·시점 정보가 보존된다. |
| CSV 왕복 | 쉼표, 따옴표, 줄바꿈, 빈 측정값, 제외 사유를 처리한다. 원본 숫자를 유지한다. |
| CSV 오류 | 비수치 값과 잘못된 시간·거리의 오류를 알린다. 빈 측정값을 0으로 간주하지 않는다. |
| CSV ID·보정 | 중복 원본 ID는 새 고유 ID로 변환한다. 행마다 다른 주변광 등 보정 설정이 섞인 CSV를 하나의 실험으로 조용히 합치지 않는다. |
| 그래프 간격 | 누락·제외된 원본 행 사이를 정규화한 실측선이 이어 그리지 않도록 `gapBefore` 정보를 보존한다. |
| 업로드 원본 | `Run.originalCsv`로 불러온 원본 텍스트를 JSON에 보존할 수 있다. 스키마는 UTF-8 10MB를 넘는 원본이나 문자열 외 값을 거부한다. |
| CSV 수식 방지 | 텍스트 필드가 스프레드시트 수식으로 실행되지 않도록 이스케이프한다. 음수 측정값은 숫자로 유지한다. |
| 수신 버퍼 | 줄 중간 분할, CRLF 분할, 한 청크의 여러 줄, 미완성 꼬리, 과도한 프레임 길이를 처리한다. |
| 프레임 해석 | 사용자가 정한 채널을 선택하며 빈 필드, 잘못된 숫자와 범위 밖 채널을 거부한다. |
| JSON 유효성 | 잘못된 차시/단계, 중복 실험·측정 ID, 잘못된 예상 구조, 비유한 수치, 없는 활성 실험 참조를 거부한다. |
| POE 기록 | JSON 왕복 후 최초 예상과 관찰·성찰이 서로 다른 필드로 보존된다. |
| 브라우저·모의 연결 | 미지원 안내와 모의 읽기 스트림의 연결·수신·해제·재연결을 검사했다. 사용자가 통신 설정을 확인하지 않으면 기기 선택을 호출하지 않는다. |

`domain.ts`, `serial.ts`, `domain.test.ts`는 별도 TypeScript 검사도 통과했다. 최종 전체 앱 빌드 결과는 프로젝트 루트의 완료 안내에 함께 기록한다.

## 과학적 해석의 제한

- 모터 구동값 255는 속력이나 거리가 아니다. 거리 추정은 줄자·시계로 확인한 실제 속력과 기준 시점을 사용한다.
- 원시값에는 임의로 lx를 붙이지 않는다. 단위와 선형성 확인 기록은 교사의 실제 검증이 필요하다.
- `상대 등급 변화`는 선택한 유효 기준 밝기에 대한 변화다. 이 장치로 실제 별의 겉보기/절대 등급을 측정했다는 뜻이 아니다.
- 같은 광원에서 이상적으로 거리 2배는 밝기 1/4, 3배는 1/9, 10배는 1/100이다. LED 방향성·반사광·주변광·센서 포화·가속은 교실 결과를 달라지게 할 수 있다.
- 5등급 차이는 정확히 100배이며 한 등급 차이는 약 2.512배다. 2.5의 5제곱이 정확히 100이라는 표현을 사용하지 않는다.
- 절대 등급의 기준은 10pc이며 10광년이 아니다. 소광을 무시하는 모형에서만 거리와 등급 관계를 단순화한다.
- CSV에서 해석할 수 없는 행은 오류를 알리고 수치 표에 넣지 않는다. 업로드 원본 텍스트를 보존하여 나중에 확인할 수 있다. 분석 제외가 원본 삭제를 의미하지 않는다.

## 브라우저·화면 검증

루트 작업에서 실제 브라우저 QA를 진행한다. 이 문서 작성 시점에는 다음을 자동 테스트 통과와 동일하게 주장하지 않는다: 전체 3~5차시 클릭 흐름, 새로고침 복원, 파일 선택을 통한 JSON/CSV 복원, PNG 다운로드, 인쇄/PDF 출력, 외부 사이트 새 탭 복귀, 노트북·태블릿의 이미지 자름·제목 대비·차트 조작. 최종 검증 결과와 실행 화면은 루트 완료 안내에서 확인한다.

## 실물 미검증

실제 USB 권한 선택, 보드 식별, 펌웨어의 송신 설정, 밝기 채널·포트·단위·선형성·포화, 기기 분리 시 동작, 측정 주기, 마퀸 모터·B 버튼 정지·직진성은 **실물 검증 전**이다. 자동 테스트의 모의 연결 성공은 실제 기기 호환성 증명이 아니다. 구체적인 순서는 [센서 조사 문서](sensor-research.md)를 따른다.
