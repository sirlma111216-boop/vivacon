# 외부 콘텐츠와 확인 상태

확인일: 2026-10-28 (Asia/Seoul). 비바샘 원본 저작물은 다운로드·재배포·임베드하지 않는다. 제공된 원본 URL을 새 탭으로 연결한다. 링크가 열린 사실은 학습 완료의 증거가 아니다. 학생이 돌아와 관찰 기록을 쓰고 직접 완료 표시한다.

## 이지온 직접 수집 안내

[이지온 홈](https://ezon.ai/)과 [유선 체험](https://ezon.ai/sandbox)을 별도 안내에서 연결한다. 요청자가 2026-10-28 제공한 이지온 실제 화면 10장을 `public/assets/ezon/step-01.png`부터 `step-10.png`까지 원본 그대로 보존해 사용했다. 생성 이미지가 아니다. 안내는 제공 화면에 나타난 블록 코딩, 업로드, 보드 재연결, 수집, 그래프 흐름을 설명한다. A0·COM3는 화면 예시, 밝기 범위는 단위 미확인 센서값이다. 웹 주소 응답을 확인했으나 이번 작업에서 실제 기기 연결·업로드·수집·파일 다운로드를 수행하지 않았다. 다운로드 형식, 이 앱과의 직접 호환, 외부 서비스의 향후 메뉴는 보장하지 않는다.

## 마퀸 예시의 공식 근거

- [DFRobot ROB0148 모터 제어](https://wiki.dfrobot.com/rob0148-en/docs/20849): Maqueen Lite 대상과 공식 확장 연결을 확인했다.
- [공식 pxt-maqueen 소스](https://github.com/DFRobot/pxt-maqueen/blob/master/maqueen.ts): `motorRun`, `motorStop`, `Motors.All`, `Dir.CW` 및 블록 속도 입력의 0~255 범위를 확인했다. 최신 소스의 분류 이름에 v4/v5가 함께 나타나므로 하드웨어별 지원을 일반화하지 않는다.
- [MakeCode onButtonPressed](https://makecode.microbit.org/reference/input/on-button-pressed): 버튼을 눌렀다가 놓는 이벤트임을 확인했다. 예제는 별도로 `buttonIsPressed`를 반복 확인하여 B를 계속 누른 상태도 정지에 반영한다.
- [MakeCode 실행 시간](https://makecode.microbit.org/reference/input/running-time)와 [협력적 실행](https://makecode.microbit.org/device/reactive): 시작 후 경과 밀리초와 짧은 반복 흐름의 근거다.

제공 코드는 위 API를 사용해 이 앱에서 직접 작성한 예시다. 실제 하드웨어에서 컴파일·전송·제동 시간을 측정한 것이 아니다. Plus, Plus V2/V3, Lite V5 등 다른 기기에 그대로 맞는다고 주장하지 않는다. HEX를 제공하지 않으며, 실제 기기와 확장 버전 확인 후 MakeCode에서 내려받는다.
