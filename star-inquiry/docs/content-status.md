# 외부 콘텐츠와 확인 상태

확인일: 2026-10-28 (Asia/Seoul). 비바샘 원본 저작물은 다운로드·재배포·임베드하지 않는다. 제공된 원본 URL을 새 탭으로 연결한다. 링크가 열린 사실은 학습 완료의 증거가 아니다. 학생이 돌아와 관찰 기록을 쓰고 직접 완료 표시한다.

## 이지온 직접 수집 안내

[이지온 홈](https://ezon.ai/)과 [유선 체험](https://ezon.ai/sandbox)을 별도 안내에서 연결한다. 요청자가 2026-10-28 제공한 이지온 실제 화면 10장을 `public/assets/ezon/step-01.png`부터 `step-10.png`까지 원본 그대로 보존해 사용했다. 생성 이미지가 아니다. 안내는 제공 화면에 나타난 블록 코딩, 업로드, 보드 재연결, 수집, 그래프 흐름을 설명한다. 화면의 A0·COM3는 예시이며, 이후 제공된 하드웨어 원본 사진 39에서는 이번 구성의 A0 물리 연결을 별도로 확인했다. 밝기 범위는 단위 미확인 센서값이다. 웹 주소 응답을 확인했으나 이번 작업에서 실제 기기 연결·업로드·수집·파일 다운로드를 수행하지 않았다. 다운로드 형식, 이 앱과의 직접 호환, 외부 서비스의 향후 메뉴는 보장하지 않는다.

## 마퀸 MakeCode 화면 해설

요청자가 제공한 실제 화면 9장을 `public/assets/maqueen/scene-01.png`부터 `scene-09.png`까지 원본 그대로 사용한다. 새 프로젝트·이름·확장 메뉴·`maqueen` 검색·v4/v5 분류·코드·다운로드 메뉴·파일 저장·HEX 확인을 장면별 HTML 해설과 함께 제공한다. 실제 장비용 확장은 하드웨어 모델과 버전을 확인해 선택한다.

6번 화면에서 확인되는 코드는 시작 하트, A 이벤트의 초음파 읽기 `<5`이면 정지/그 외 전체 모터 정회전 255, 무한반복의 `<5` 정지, B 이벤트의 전체 모터 정지다. 하트는 연결 성공 표시가 아니고, 화면에는 시작 모터 정지·준비 시간·시간 종료 자동 정지가 없다. 무한반복에는 전진하는 ‘아니면’ 분기가 없으며 B 정지는 재출발 잠금이 아니다. 255는 속력 단위가 아니고 5cm는 실제 정지 여유를 보장하는 값이나 LED–밝기 센서 사이 거리가 아니다.

기존 JavaScript는 **추가 선택 · 준비 시간과 자동 정지 코드**로 구분한다. 해당 변형에는 시작 모터 정지·준비 시간·B 눌림 확인·시간 종료 정지가 있지만 초음파 정지는 없다. 화면 코드와 동일하다고 소개하지 않는다. [MakeCode 공식 전송 안내](https://makecode.microbit.org/device/usb)에 따라 HEX 파일을 `MICROBIT` 드라이브에 옮기는 절차를 설명하며, 앱이 HEX를 생성하거나 보드에 자동 업로드했다고 주장하지 않는다.

## 마퀸 예시의 공식 근거

- [DFRobot ROB0148 모터 제어](https://wiki.dfrobot.com/rob0148-en/docs/20849): Maqueen Lite 대상과 공식 확장 연결을 확인했다.
- [공식 pxt-maqueen 소스](https://github.com/DFRobot/pxt-maqueen/blob/master/maqueen.ts): `motorRun`, `motorStop`, `Motors.All`, `Dir.CW` 및 블록 속도 입력의 0~255 범위를 확인했다. 최신 소스의 분류 이름에 v4/v5가 함께 나타나므로 하드웨어별 지원을 일반화하지 않는다.
- [MakeCode onButtonPressed](https://makecode.microbit.org/reference/input/on-button-pressed): 버튼을 눌렀다가 놓는 이벤트임을 확인했다. 별도 선택형 시간 제어 예시는 `buttonIsPressed`를 반복 확인하여 B를 계속 누른 상태도 정지에 반영한다. 제공된 화면 코드에 이 추가 확인이 있다고 설명하지 않는다.
- [MakeCode 실행 시간](https://makecode.microbit.org/reference/input/running-time)와 [협력적 실행](https://makecode.microbit.org/device/reactive): 시작 후 경과 밀리초와 짧은 반복 흐름의 근거다.

별도 선택형 JavaScript는 위 API를 사용해 이 앱에서 직접 작성한 시간 제어 예시다. 실제 하드웨어에서 컴파일·전송·제동 시간을 측정한 것이 아니다. Plus, Plus V2/V3, Lite V5 등 다른 기기에 그대로 맞는다고 주장하지 않는다. HEX를 제공하지 않으며, 실제 기기와 확장 버전 확인 후 MakeCode에서 내려받는다.
