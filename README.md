# 별빛 탐구실 · 별빛의 거리를 재다

별빛 탐구실은 중학교 과학 3~5차시 POE 웹앱입니다. 앞선 NC1395의 1~2차시 탐구와 디자인을 참고했으며, 독립된 이름으로 구성했습니다. React·TypeScript·Vite·Apache ECharts로 만들었으며 별도 서버 없이 브라우저에 학습 기록을 저장합니다.

**실행 사이트: [별빛 탐구실](https://vivacon.pages.dev/)**

## 실행

Node.js 24에서:

```sh
cd star-inquiry
npm ci
npm run dev
```

브라우저에서 터미널에 표시되는 주소를 엽니다. 배포 파일은 `npm run build`로 생성되는 `star-inquiry/dist`입니다. `npm test`로 과학 계산·CSV·백업·이지온 파일 읽기 테스트를 실행합니다.

## 학습 흐름

- **3차시:** 개인/모둠 최초 예상 그래프와 이유 보존, 거리–빛의 세기 조작 모형, 변인·측정 계획·설계 점검.
- **4차시:** 오늘의 실험 → 자동차 준비(마퀸 MakeCode 9장면, 실제 속력 3회 측정) → 이지온 연결(센서 A0·USB, 이지온 블록 업로드, LED 끈 값·시작값 확인) → 측정하고 저장(이지온 수집·그래프·CSV 다운로드) → 가져와 비교(이지온 CSV 가져오기, 출발 시각 표시, 주변광 보정, 반복 비교, 분석 제외 사유, 작성자별 관찰 후 설명). 장비가 없으면 연습 데이터나 직접 입력을 씁니다. 준비 시간과 자동 정지 JavaScript는 초음파 정지 화면과 구분한 별도 선택형 예시입니다.
- **5차시:** 비바샘 원본 활동 연결, 전구 수와 밝기 비, 유효한 값의 상대 등급 변화, 10pc 모형, 자체 형성평가와 성찰.
- **이지온 측정 안내:** 4차시의 측정 방법입니다. 제공된 화면 10장으로 블록 구성·업로드·보드 연결·수집·그래프 확인·저장을 설명하며, 4차시 본문에 필요한 부분이 나뉘어 나오고 상단 메뉴와 시작 화면에서 전체를 다시 볼 수 있습니다.
- **장비 사용 설명서:** 원본 사진 24장과 설명용 그림 12장을 준비물·자동차·센서 연결·측정 자리로 묶었습니다. 필요한 안내는 4차시 본문에 순서대로 표시하며, 추가 사진 확대는 선택할 수 있습니다.
- **저장:** 로컬 자동 저장, JSON 백업·복원, CSV 및 원본 CSV 저장, 그래프 PNG, 인쇄/PDF 보고서, 샘보드 공유용 텍스트. 자동 동기화·자동 게시 기능은 없습니다.

실험 전에는 JSON 백업을 보관하세요. 새 기기나 다른 주소로 이동할 때 기록은 자동 이전되지 않습니다. 교사용 패널은 인증 기능이 아닙니다.

## 센서 데이터와 검증 범위

별빛 탐구실은 보드와 직접 통신하지 않습니다. 센서값은 이지온에서 수집하고, 이지온 **데이터 다운로드** CSV(`수집시간,센서 1`)를 4차시 **가져와 비교**에서 불러옵니다. 수집시간(`23:03:33.374` 등)은 첫 기록부터 지난 초로 바꾸고 센서값은 원본 그대로 보존합니다. 파일 형식은 공개 이지온 웹 클라이언트의 다운로드 코드로 확인했으며, 실제 장비에서 내려받은 파일로는 아직 시험하지 않았습니다.

제공된 장비 원본 사진 39에서 밝기 센서의 **A0 물리 포트 연결**을 확인했습니다. 센서값의 단위·선형성은 별도 검증 대상이며, 원시값에 lux를 붙이지 않습니다.

연습 데이터는 화면·CSV·JSON·보고서에서 출처를 보존합니다. 실측 결과로 사용하지 마세요. 속력·주행 기준 시점 미확인 시 거리 추정이 불가능하며, 선형성과 단위가 미확인인 원시값은 등급으로 환산하지 않습니다.

## 자동 배포

대상 저장소: `https://github.com/sirlma111216-boop/vivacon`

Cloudflare Pages 프로젝트 `vivacon`에 Git으로 연결되어 있으며 다음 설정을 적용했습니다.

| 설정 | 값 |
|---|---|
| 프로덕션 브랜치 | `main` |
| 프로젝트 루트 | `star-inquiry` |
| 빌드 명령 | `npm test && npm run build` |
| 출력 디렉터리 | `dist` |
| Node 버전 | `24` |

`main`에 push하면 Cloudflare가 자동 빌드·배포합니다. GitHub Actions도 같은 테스트와 빌드를 수행합니다. 2026-10-28 첫 배포 성공과 HTTPS 사이트 실행을 확인했습니다. 자세한 설정과 확인 기록은 배포 문서에 있습니다. API 토큰이나 학생 데이터를 저장소에 넣지 마세요.

## 이미지

사용자가 제공한 PNG 3개를 `star-inquiry/public/assets/astronomy/`에 원본 그대로 보존했습니다. 생성 삽화이며 사료·공식 제품 사진·비바샘 공식 이미지·실측 데이터가 아닙니다. 수치·방향·그래프·10pc 관계는 HTML/SVG/Canvas로 따로 구현했습니다.

장비 안내는 기존 일반 실험 삽화를 제공된 하드웨어 매뉴얼 자료로 교체했습니다. `star-inquiry/public/assets/hardware/`에는 설명용 삽화 12장과 원본 장비 사진 24장을 보존합니다. 새 이미지를 생성하지 않았습니다. 방향·포트·버튼이 삽화와 다르면 원본 사진을 우선하며, 전원은 사진 26, USB 연결은 사진 44를 기본 상세 근거로 사용합니다. 사진 46은 micro:bit 뒷면 소개용이고 장착 방향은 사진 48을 참고합니다.

이지온 조작 안내에는 사용자가 제공한 실제 화면 PNG 10개를 `star-inquiry/public/assets/ezon/`에 원본 그대로 보존했습니다. 화면에 보이는 수집값과 그래프는 조작을 설명하는 예시이며 거리–밝기 실험의 검증 결과가 아닙니다.

마퀸 코딩 안내에는 제공된 MakeCode 실제 화면 9개를 `star-inquiry/public/assets/maqueen/`에 원본 그대로 보존했습니다. 블록 화면의 255는 실제 속력이 아니며 초음파 5cm 조건도 LED–밝기 센서 간 측정 거리가 아닙니다.
